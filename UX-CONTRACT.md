# Whiteboard interaction contract

Canvas text, document cards and sticky notes share seven font choices: Inter, Caveat, Fira Code, Lora, Nunito, Roboto Condensed and Patrick Hand. Existing sans/hand/mono IDs retain their meaning. Font buttons expose the selected family and preserve editor focus. Font IDs persist through board backups and room sync. Canvas startup and raster/vector export wait for bundled font faces to load; standalone SVG viewers may use the documented fallback stack when a font is not installed.

Empty inline editors size from their actual placeholder using the active font metrics. Hints inherit the chosen family, weight and style, use explicit high-contrast placeholder colors, and wrap within constrained viewports. Editor bounds remeasure after font loading and viewport/split changes. Document/sticky editors preserve card widths; editing surfaces stay visible near viewport edges without changing saved canvas coordinates.

Shape and card creation tools return to Select after a successful insertion. Pencil is the deliberate exception: it stays active between strokes, pointer departure, cancellation and undo/redo, with no automatic selection outline. Double-clicking a stroke or choosing Select enables normal editing. Other newly created elements get the same blue selection outline, resize handles and connector ports as manually selected elements. Clicking blank space clears selection; drawing another item requires choosing its tool again. Text, document, sticky and code creation still open their inline editors, with selection controls visible when editing finishes. Cancelled or undersized drafts leave the chosen tool available for retry. Eraser and Hand remain active until changed. Each item remains separately undoable. Double-click text editing belongs to Select mode. Icon insertion selects the inserted icon. Select-mode connections select the newly created arrow for editing.

The current user brief and README define a personal, local-first tool. No server account, billing, or team permissions are implied by a local workspace. Explicitly shared rooms synchronize through a configured WebSocket service using UUID invite capabilities.

Opening Appearance with Arrow selected exposes Straight, Elbow and Curved routing. Routing buttons expose their selected state. Changing routing preserves endpoint bindings, caps, labels and animation; the choice also applies to subsequent arrows. Arrows saved without routing render and report Straight. Dragging a straight arrow's center diamond switches it to a manually curved arrow; the handle follows perpendicular pointer displacement. The signed Bend (px) input provides a keyboard alternative. Choosing Straight resets the bend. Manual curves retain their bend when attached shapes move or resize, support undo/redo and cancellation, and use shared geometry for hit testing and exports.

In personal boards, canvas undo/redo covers diagram edits; native textarea editing history covers typed notes. Board changes reset selection/history and viewport. Board metadata includes notes, view mode, grid and snap settings. Existing boards without a workspace belong to Personal workspace. Creating an empty workspace does not remove or switch the currently displayed board. Clicking a board selects it and closes the workspace drawer; moving it updates its stored workspace.

Workspace names are required and limited to 80 characters. Search is local and immediate with an explicit clear action. Deleting a board requires an inline confirmation that names the board and includes its notes. Clearing a board requires a modal confirmation; canvas removal is undoable but removed notes are not in canvas history. Imports create new IDs and never replace an existing board. JSON is the lossless editable backup; SVG and draw.io are interchange exports.

Split dragging has arrow-key, Home and End alternatives and a double-click reset. Main canvas has no document scroll. Pointer capture keeps a split drag active outside the handle. Notes and preview wrap long content. IME composition is excluded from editing shortcuts.


RoomSession owns Yjs elements, collaborative Markdown text, local-origin undo and awareness. Room edits unlock after first sync. Once initialized, offline edits remain in the live Y.Doc and merge on reconnect. Same-element concurrent shape edits resolve to one CRDT map value; notes use character-level merge. Server room documents persist in PostgreSQL when configured, otherwise on disk, with UUID paths validated before accepting sockets. tests/collaboration.test.mjs exercises real two-client sync, presence and persistence.

Remote scene updates preserve unfinished local eraser/move gestures. RoomSession publishes element changes rather than replacing the room snapshot; unchanged stale objects cannot recreate a peer-deleted object. Regression coverage is in tests/engine.test.mjs and tests/collaboration.test.mjs.

Leave room is available in the header, collaboration dialog and initial connection state. It destroys the local session once, clears cursor presence immediately, and returns to the last personal board (creating one if necessary). The room and its local copy are preserved, and other participants remain connected.

Opening Appearance while Text is selected exposes text options. Clicking the canvas clears any previous selection and opens a focused editor at the click. Text styling buttons preserve textarea focus and update the active draft; font controls never modify a previously selected shape. The editor grows with content and remains vertically scrollable at viewport limits.

Pointer-downs that create text, sticky or document editors cancel the canvas default mouse-focus action and do not capture the pointer. Editor focus is scheduled after that event sequence so a newly opened empty draft cannot disappear on the same click. Toolbar tool selection updates the engine synchronously before the next canvas click.

Ordinary canvas text uses a transparent, borderless editor at the text position. Document cards and sticky notes remain explicit tools. Ctrl/Cmd+B, I, U and Shift+X toggle whole-element bold, italic, underline and strikethrough, while sidebar buttons preserve editor focus. Formatting persists through editing, undo/redo, room sync and exports. IME composition bypasses shortcuts.

Selected elements expose a single circular connector port at each side center and four square corner resize handles. Painting and corner hit testing share renderer.getResizeHandles. Dragging the selection outline beside a port resizes from that side, with a directional resize cursor; the port hit area remains exclusively for connectors. Corner/endpoint dragging takes priority where hit areas overlap. Selection has a solid outline; only the selected element shows ports in Select mode. The Arrow tool reveals target ports while connecting. Bound arrow endpoints are filled blue instead of showing another set of target handles. Frames retain edge resize handles because they have no connector ports.

Resize gestures preserve the pointer-to-handle offset, so grabbing the padded outline does not jump the element. Text scales its font and remeasures its bounds; freehand transforms its actual points. Cancellation through Escape, pointer cancellation, capture loss, tool changes or window blur restores the latest committed scene, including received peer updates. Secondary pointers cannot replace or cancel the active gesture. Pan cursors take priority over selection controls.

Icon search uses the native dialog for focus/Escape behavior, cancels requests when closed or superseded, matches results to the exact query, offers clear/retry actions and handles IME composition. Imported SVG keeps inherited styles, groups, transforms, gradients and local masks while excluding active/remote content. Image decoding completes before insertion; canvas repaint and raster exports wait for decoded icons. Canvas icons have no badge or caption, including previously saved icons.

Appearance settings show controls relevant to the selected element/tool. Document/list and line/corner details are collapsed by default. Icon controls exclude background and border styling. Toolbar buttons expose shortcut keys in tooltips and keyboard metadata; a ResizeObserver positions appearance settings below wrapped toolbars. Workspace move controls use a collapsed disclosure on each board.

The export panel distinguishes editable projects from viewing formats. .knotleaf files are versioned UTF-8 JSON with explicit project/canvas/notes scope. Imports and Markdown opens create a new board and preserve existing work; imported workspace IDs never select a foreign workspace. A complete PDF captures all canvas bounds, not the visible viewport, and paginates formatted notes. Empty canvas image exports show a useful error; empty PDF sections receive a labelled empty page. PNG scaling is bounded by canvas dimension and pixel budgets. Object URLs remain valid until after download starts. PDF/PNG/SVG cannot reopen as editable projects, and the UI states this.

Double-click blank space creates plain text at the exact canvas-space pointer, accounting for pan/zoom. Double-click any element selects it and switches to Select, regardless of the active tool. Double-click existing text while already in Select keeps its inline editor behavior. Alt+double-click inside a shape in Select creates a separately editable text element with a relative container offset. Click-only creation tools and erasing over existing content wait 500 ms to distinguish selection intent; a drag starts immediately after 4 px movement. Deferred actions cancel on tool changes, pointer cancellation, window blur and engine destruction. Moving/resizing the shape carries its text; copying/duplicating/deleting the shape includes contained text, and selection export includes it. Dragging text outside its parent detaches it. Existing text opens with a grapheme-safe caret near the click; legacy shape labels become attached text at the pointer in an undoable edit, while frame titles and arrow captions retain their dedicated editors. Smart guides show transient red edge/center alignment and nearest gap measurements during drags, highlight equal gaps, and disappear on completion/cancellation. Alt disables magnetic alignment; grid snapping takes priority. Guides are never scene elements or exported.

BoardTools owns find, history and custom-template workflows in one native dialog. Local search supports clear/no-results states and caps results at 200; selecting a canvas result changes to Canvas view and focuses it, while a notes result opens the source and selects the exact match. Local snapshots are throttled before storage access, retained within 20 entries/8 MB per board, and automatic captures occur before edits at most once every five minutes. Recovery/templates create new boards instead of overwriting current or shared data. Storage errors are visible. Board deletion clears its local history; template deletion affects only the library entry. PresentationMode owns frame navigation with keyboard/select alternatives and Escape; the engine is read-only while presenting and viewport restoration preserves the editing context. Frame geometry changes refocus slides; unrelated peer edits do not reset the presentation viewport.

CodeEditor owns inline code editing and the shared HighlightedCode renderer for notes. Notes source uses an aligned highlight layer for fenced code, including while a closing fence is unfinished. C + canvas click creates a code card at the pointer; double-click reopens it. Auto detection updates while typing; the native language selector can override uncertain detection. Code typing uses one typography contract for coloured glyphs and the transparent caret/input layer, Tab inserts two spaces, Enter preserves indentation, and Escape/Ctrl+Enter finishes. Code remains editable in `.knotleaf` files and exports via the shared canvas renderer. Empty cards are retained. RoomSession uses a separate Y.Text per code ID so concurrent text edits merge; card deletion wins over stale edits. Code is not executed.

The teaching extension uses standard PostgreSQL or durable local files for room capabilities, content and timestamps; personal workspaces remain browser-local. The Node hub owns `/api/rooms` creation and validates origin, size and content before saving initial Yjs state. Serverless frontends proxy to that hub. Stored state loads before sync; failed storage never becomes an empty room. Orphan `.bin` recovery files cannot create new rooms or renew expiry. Invite capabilities grant editing and call access; there are no teacher/student account roles.

ClassroomSession owns native WebRTC with four stable media slots (mic, camera, screen video and screen audio), perfect negotiation, early ICE queuing and device cleanup. `/classroom/UUID` is a separate WebSocket signaling endpoint on the same room host. It validates stored room/origin, assigns sender IDs, routes only within the room, bounds payloads/rates, enforces a default 8-person limit (configurable 2–12), and uses heartbeats/leave cleanup. Camera/mic begin off. Calls are small-group mesh, not a large-class SFU. No gRPC or paid video-service SDK is necessary. Optional coturn configuration issues 12-hour HMAC credentials without exposing the relay secret; the deployment now enables the verified public Google STUN endpoint; TURN remains opt-in.

Classroom owns a minimizable nonmodal panel that stays connected while hidden. Explicit controls expose mic/camera/screen state, network failures/rejoin, and Leave call independently of Leave room. Remote audio survives minimization; blocked autoplay provides Enable sound. Chat is ephemeral. LocalRecorder owns explicit capture and local file download, never upload; cleanup stops acquired tracks and a 512 MB cap saves bounded recordings. Browser media and cross-network/TURN verification require real devices.

The configured production topology is Vercel frontend, one Render Node/signaling hub and Neon room storage. Public URLs/allowed origins use the Vercel app domain and existing Render endpoint. Render's Dockerfile runs only on the host, auto-deploy waits for CI, and temporary recovery files do not replace Neon durability. Local Compose stacks and CI database containers are removed. Database/relay secrets remain server-only; a generated relay secret without real endpoint URLs does not enable relay service. Personal local workspaces and locally saved recordings remain intentional exceptions to server persistence.

Classroom renders its always-mounted side panel in a body portal so the backdrop-filter header cannot collapse or clip it. Opening is independent of room sync/media permissions, minimizing/Escape restores focus, and call/recording state survives minimizing. A personal-board action creates a shared room and navigates with `?classroom=1` to open the panel immediately. Errors stay visible inside the panel.

Classroom keeps a visible, selectable invite URL above join/call controls, with copy feedback and manual-copy fallback. Audio source is a native select: Auto names the active microphone after capture permission, device changes refresh choices, and choosing while muted never enables capture. Switching acquires before stopping the old source; device labels stay local. Screen sharing states whether tab/screen audio is included. InstallWebApp owns a quiet header action and body-portaled native instruction dialog; it captures browser install prompts, handles dismissal/failure and installed standalone state. The manifest uses standalone display and PNG icons. No offline caching or forced reloads: deployed website updates load on normal reopen/reload without disrupting ongoing edits/calls.

Document notes use one typography contract for textarea and highlighted source, one scroll owner, no forced minimum editor height, and preserved cursor/scroll across preview. Formatting operates on whole lines or selected text without inserting sample content; Tab/Shift+Tab handle selected lines. Outline excludes code fences and is capped relative to panel height. Canvas document cards start empty, preserve their surface while editing, and expose a compact icon toolbar with an explicit Finish action. They have a quiet border and no overlapping title label. Renderer list/quote alignment resets per line so preceding centered text cannot shift content.

Room API, canvas and classroom connections share runtime configuration from `/api/collaboration-health`. Integrated servers return their same-origin hub; serverless frontends return the configured external hub. Invites always use the current website origin. Local `bun dev` / `start:local` ignore hosted settings in memory, use `.collab-data/`, bind to loopback by default and restrict room origins to the chosen local addresses. Existing environment files and personal boards remain intact. Production creation allows host startup within a 55-second upstream timeout and 60-second function duration. Both create entry points share one in-flight request; successful responses must contain a valid room UUID before caching/navigation. Failed local caching does not discard a server-saved room. Legacy boards normalize missing notes. Personal startup excludes room caches, and selecting a cached room navigates to its synchronized route. Failed initial sync preserves the cache and offers Retry/Leave; browser storage access failures do not prevent starting a personal board.

Room retention follows the explicit user requirement: delete every room 24 hours after creation, including existing rooms. Edits do not renew expiry. Server storage is authoritative, checks the deadline on reads and writes, and refuses resurrection from orphan recovery files. Drawing/call connections close at the deadline; the browser removes room caches/history and shows a terminal expiry message. Personal boards and explicit exports remain independent. Startup/minute cleanup plus scheduled production cleanup delete expired persisted data; a sleeping host or delayed schedule can postpone physical cleanup but cannot extend access.

RefreshWebApp owns the explicit header Refresh action in browser and installed standalone windows. It checks the current document with a no-store HEAD request, finishes current editors and saves the latest board immediately before reloading the same URL. Failed reachability or saving leaves the app open with a dismissible accessible error. Duplicate clicks are blocked. Disconnected shared edits must reconnect before refresh, and queued outgoing room bytes drain before reload. Recording/startup disables Refresh until recording is stopped and saved. Refresh is user initiated; it does not clear board storage or force background updates. Reloading ends active calls and reconnects the same room route.

Selected lines share the arrow midpoint diamond and signed numeric Bend (px) control. The quadratic curve follows perpendicular midpoint dragging in either direction; zero restores a straight segment. Endpoint changes, movement, history, room synchronization and editable exports retain the bend. Canvas painting, hit testing, selection, bounds and exports use renderer.computeLinePath.

The Paint workspace, its toolbar entry, raster editing operations and `.kpaint` workflows are removed. The whiteboard retains its drawing, text and shape tools. Existing embedded images remain rendered, movable, resizable, synchronized and portable in project files and exports.

Embedded PNG/JPEG/WebP board images have bounded data URLs, no remote requests, normal move/resize/selection, portable project serialization and shared-room validation. PNG/PDF wait for decoding; SVG embeds self-contained images; draw.io uses image cells. Board storage failures remain visible through the shared save-error workflow.

Fill controls and bucket-tool entry points are removed from the interface, including the B shortcut. Drawing/text color and object opacity remain. Pick color (K) updates only future drawing color and returns to Select after sampling. Older fills, transparency and patterns remain readable, editable as artwork and portable through saving, rooms and exports. New canvas, note and stroke colors are muted; no migration changes existing artwork.

Canvas background settings are normalized by `lib/background.mjs`, persist in personal boards and editable backups, synchronize through room metadata, and participate in room undo. The server seeds and persists those settings; malformed/missing values fall back to charcoal solid/opaque. The checkerboard and grid are editing guides, excluded from exports. PNG/PDF/SVG honor background color/style/opacity unless the user explicitly requests a transparent canvas export. Draw.io remains an interchange format with solid fill approximations for patterns.

Appearance visibility is controlled only by the user's Open/Hide actions in Canvas. Every fresh visit starts hidden, regardless of old stored preferences. Shape creation, inserted elements, selection changes, tool changes and text editing never open it automatically. An explicitly opened panel stays open until hidden. An accessibly named palette button opens the nonmodal panel; its close button and Escape hide it and restore focus to that button. Canvas owns the session state, preserving a user's explicit choice across board changes and presentation remounts. No browser storage is needed.

Canvas focus view (header button or Shift+Z) hides the header, drawing toolbar, Appearance, arrangement and zoom controls, and notes pane so the editable canvas uses the full window. One small Show controls button, Escape or Shift+Z restores controls. It closes Appearance explicitly, preserves the saved view mode/notes split, commits active editors and cancels gestures without changing the chosen tool. Keyboard shortcuts still draw normally. Typing, IME composition, open dialogs and presentation take priority over focus shortcuts. Hidden header/classroom UI stays mounted so active calls and recordings continue. The standard drawing toolbar uses one compact, horizontally scrollable row instead of wrapping over the canvas.

Canvas text starts with “Start typing…” and focuses automatically. Appearance focus stays within the editing session so font, alignment and color controls can format an uncommitted draft. Clicking elsewhere or Ctrl/Cmd+Enter/Escape commits the latest value. Empty free text creates no element; clearing an existing free-text element removes its selection ID. Document/sticky text wraps; long free-text lines scroll.
