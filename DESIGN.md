# Knotleaf Desk Design System

## Overview

### Creative North Star
An Eraser-inspired drawing board: black/white surfaces with one restrained theme accent, a centered grouped tool strip, a spacious dotted canvas and Caveat handwriting for new artwork. Contrasting attachment ports make diagram structure visible.

### Product context and register
Personal diagrams and project notes, primarily used on desktop with keyboard and pointer. English interface; no market-specific business rules. This is a product tool, not a marketing page. Repository README and current user instructions supply the product context. Keep Dark and Light as equal drawing-board surfaces. The branch-veined leaf mark is the expressive signature; controls remain familiar. Avoid decorative gradients, giant toolbars, and ornamental cards.

Runtime sources are canonical: `app/globals.css` owns global styles and scrollbar tokens; `app/layout.tsx` owns font variables; shared components own utility-class geometry; `draw/renderer.ts` owns canvas visuals and contrasting ports. This document records these implemented values, rather than generating a separate theme.

## Colors
Default Midnight uses #000000 canvas/panels in Dark and #ffffff in Light. Buttons and structural borders stay neutral. Only selected tools, primary actions and keyboard focus use the current theme accent. The legacy black ID identifies Midnight; mono remains Lagoon. lib/workspaceThemes.ts owns optional Paper, Slate and Forest palettes for independently scoped Canvas and Notes. Red alignment guides retain their measurement role; artwork and syntax colors remain explicit content choices.

## Typography
Inter for controls, Fira Code for Markdown source and coordinates, Caveat as the default for new canvas writing, sticky notes and built-in template lettering. Canvas text also offers Lora (serif), Nunito (rounded sans), Roboto Condensed and Patrick Hand (printed handwriting). The appearance picker keeps eight familiar families in a compact two-column quick group. At the user’s request it has no More fonts dropdown. FontSelect owns grouped options for selected Notes text and document appearance, deliberately retaining platform popup geometry. The shared catalogue has 31 families across Everyday, Serif, Handwriting, Playful & display, and Monospace; catalogue labels keep the interface font for legibility, while the canvas and note content show the chosen face. New choices include Fredoka, Baloo 2, Permanent Marker, Bangers, Lobster, Special Elite and elegant reading faces. `draw/fonts.ts` owns family IDs, labels, CSS-variable names and fallback stacks; `app/layout.tsx` bundles the corresponding Next fonts. Renderer, inline editor and picker use that shared mapping. Fonts are bundled by Next at build time. Notes use 16px Inter prose by default, with shared font choices and saved reading preferences; optional source uses 13px source with 24px line height. Controls remain compact without compromising focus indicators.

## Layout

Canvas editor placeholders inherit the chosen font and have explicit full-opacity muted text (#a1a1aa), with slate (#475569) on yellow sticky surfaces. Empty editors measure the complete hint, wrap it when constrained, and stay inside the canvas viewport. Font-load completion and viewport/split changes remeasure the editor. `app/globals.css` owns placeholder colors; `draw/inlineEditorLayout.ts` owns editor bounds.
48px fixed header, drawing tools flush with the top of the canvas below it. Inspector is relative to the canvas, below the tools; it scrolls internally only when necessary. Notes split starts at 360px, is draggable and keyboard resizable; below 640px it becomes a vertically stacked split. Notes contain their own vertical scroll; long prose and code wrap instead of forcing horizontal scrolling. Document toolbars keep bounded rows and overflow controls on narrow viewports. The canvas itself pans, never document-scrolls.

## Elevation & Depth
Hairline borders and flat opaque surfaces establish hierarchy. Floating panels use only a small shadow; drawing controls have 4–6px corners and no frosted-glass treatment. Modal backdrops darken the workspace. Avoid shadows on document content.

## Shapes
8px controls, 12px floating panels. Lucide icons use consistent strokes. The selectable theme-accent or black Knotleaf mark is shared by header and website favicon.

## Components
Native buttons for actions. Active view buttons expose aria-pressed. Workspace and export quality selects deliberately use platform-owned native popups. Native dialog owns modal focus, Escape and background inertness. Inline board-deletion confirmation stays inside the workspace dialog and states the consequence. Enabled buttons have hover/pointer/focus states; disabled actions are muted. No browser confirm/alert flows.

Notes toolbar, outline, source editor and GFM preview share one owner in `DocEditor`. Renderer and engine share the same connector geometry for hit testing, labels, selection and exports. Endpoint handles reconnect; connector-body movement preserves attachments. `BoardsSidebar` owns local workspace navigation.

Motion is brief functional feedback. Reduced-motion styles disable decorative animation. The app avoids skeletons and unstable placeholders. Plain labels name actions and outcomes.

## Do's and Don'ts
- Do keep notes and drawings in the same board and make attachment ports visible.
- Do reuse the shared renderer for vector export.
- Don't claim cloud collaboration or successful saving without evidence.
- Don't hide necessary content scrollbars; eliminate horizontal overflow through wrapping.

Selection controls use four square corner resize handles and one outside + connection control per side, 22 screen pixels beyond the attachment port. Code cards and frames include side-center resize squares. Other connectable elements omit them to avoid duplicate controls. The selection outline supports side resizing beside the connector dots, with directional resize cursors. Frames also keep their edge squares because they do not expose connectors.

The single-selection outline is solid and quiet. Successful shape and card creation returns to Select with the same blue outline, resize handles and connector points as a manually selected element. Clicking blank space clears the selection. Connection points belong to the selected element in Select mode; other elements reveal them only as Arrow-tool targets. Bound arrow endpoints use the blue accent. Port layers are painted once, and selection controls stay hidden while typing.

Canvas icons are standalone glyphs on transparent backgrounds, with no captions or badge cards. The appearance panel is 288px wide and constrained to the canvas viewport. Its fixed header shows a stable Appearance title and selection context, its settings area scrolls independently, and a fixed footer groups labelled selection actions. Secondary settings use native details. It follows the measured toolbar height. Drawing-tool shortcuts remain in tooltips and accessible keyboard metadata. Workspace rows use quiet surfaces and disclose move controls only when needed.

Knotleaf Desk combines the knot of connected diagrams with the leaf of a notebook. The export panel has one format selector and one content selector, with explicit editable/share-only guidance. The .knotleaf format is versioned JSON. Opening a backup always creates a new local board in the chosen workspace.

Smart guides use red #f87171 during manipulation only: dashed alignments, solid gap rulers, pixel labels and equal-spacing markers. Their strokes and labels stay constant in screen pixels across zoom. They do not appear on idle boards or in exports.

Board tools uses a single search/history/template dialog, keeping new capabilities out of the drawing chrome. Snapshot/template rows share restrained borders, explicit actions and local-storage scope descriptions.

Canvas code highlighting distinguishes purple keywords, blue function names, green strings, amber numbers/types, cyan built-ins/properties and muted comments. lib/codePalette.ts owns paired contrast-aware Dark/Light palettes shared by the inline editor and canvas/export glyphs. Canvas cards show code without a language name or selector; Copy/Finish actions float outside the content. No modal code editor. Classroom is a minimizable side panel so teaching and drawing can continue together; the Classroom component owns compact mic/camera/screen-share/leave controls, a participant grid and an explicit Chat toggle. Recording controls explain local save and audio capture limitations.

The trigger exposes expanded/controls semantics; minimizing/Escape restores trigger focus. Classroom keeps a visible, selectable invite URL above join/call controls, with copy feedback and manual-copy fallback. The manifest uses standalone display and PNG icons. No offline caching or forced reloads: deployed website updates load on normal reopen/reload without disrupting ongoing edits/calls.

Document notes use one typography contract for textarea and highlighted source, one scroll owner, no forced minimum editor height, and preserved cursor/scroll across preview. Formatting operates on whole lines or selected text without inserting sample content; Tab/Shift+Tab handle selected lines. Outline excludes code fences and is capped relative to panel height. Busy state preserves button dimensions, reduced motion disables the spinner, and failures use a body-portaled dismissible alert above the canvas.

Existing attached text reopens for editing; Alt+double-click remains supported. Other elements retain their selection/editing behavior. Keep the existing #121212 canvas, original dot/grid contrast, white default stroke and original card/sticky backgrounds.
